# Portfolio — Mudit Choudhary

Personal portfolio website for Mudit Choudhary — Machine Learning & Applied Cryptography Engineer.

## Tech Stack
- **Framework**: React 19 + Vite
- **Styling**: Tailwind CSS v4
- **Typography**: Plus Jakarta Sans, Newsreader, JetBrains Mono
- **Routing**: React Router DOM (v7)
- **Tooling**: Oxlint

## Development
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
npm run preview
```
